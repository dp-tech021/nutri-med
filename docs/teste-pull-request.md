# Teste de Pull Request

Este documento valida a capacidade da integração GitHub de:

1. Criar uma branch a partir de `main`.
2. Criar um arquivo e um commit nessa branch.
3. Abrir um pull request direcionado à `main`.

**Este arquivo é apenas um teste de integração.** Não representa a implementação do MVP, e o pull request não deve ser mesclado automaticamente.
